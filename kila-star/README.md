# KILA STAR WordPress テーマ

株式会社KILA STAR コーポレートサイト用の WordPress テーマです。
既存の静的サイト（黒×ゴールドのArt Deco調・1ページ構成）をそのまま WordPress テーマ化しています。

## 含まれるファイル

| ファイル | 役割 |
|---|---|
| `style.css` | テーマ情報ヘッダー＋サイト全体のスタイル |
| `functions.php` | スタイル/スクリプトの読み込み、メニュー登録、カスタマイザー設定 |
| `header.php` | 共通ヘッダー（ナビ・モバイルメニュー） |
| `footer.php` | 共通フッター（会社情報・コピーライト） |
| `front-page.php` | トップページ本体（Hero / About / Business / Works / Flow / お客様の声 / Contact） |
| `index.php` | 投稿一覧・検索・アーカイブ用のフォールバック |
| `page.php` | 固定ページ用テンプレート |
| `script.js` | カーソル演出・スクロール表示・お客様の声スライダーなど |

## インストール手順

1. この `kila-star` フォルダを ZIP に圧縮します（フォルダ名は `kila-star` のままにしてください）。
   - 例：`kila-star.zip` の中に `style.css` などが直接入っている状態。
2. WordPress 管理画面 →「外観」→「テーマ」→「新規追加」→「テーマのアップロード」から ZIP を選択してインストール。
3. 「有効化」をクリック。

※ FTP で設置する場合は `wp-content/themes/kila-star/` に各ファイルを配置してください。

## 有効化後の設定

- **トップページ**：`front-page.php` があるため、有効化するだけでトップページがこのデザインで表示されます（「設定」→「表示設定」の指定に関わらず適用されます）。
- **サイトのタイトル**：「設定」→「一般」でサイトタイトルを「株式会社KILA STAR」等に設定してください（`<title>` タグに反映されます）。
- **お問い合わせ・連絡先**：「外観」→「カスタマイズ」→「KILA STAR｜お問い合わせ設定」で以下を変更できます。
  - お問い合わせボタンのURL（Googleフォーム等／初期値は `#`）
  - 電話番号（初期値 `080-6523-5282`）
  - メールアドレス（初期値 `kita@kila-corp.com`）
  - **未入力の項目は自動で非表示**：空欄にした項目は、お問い合わせセクション・フッターの両方でその項目ごと非表示になります（お問い合わせボタンは URL が空欄または `#` のとき非表示）。
- **メニュー**：ヘッダーのナビは初期状態でページ内アンカー（About / Business / Works / Flow / Contact）を表示します。
  「外観」→「メニュー」で「メインメニュー（ヘッダー）」に独自メニューを割り当てると差し替え可能です（Contact をボタン風にしたい場合は、メニュー項目の「CSSクラス」に `nav-cta` を指定してください。CSSクラス欄は画面右上「表示オプション」で有効化できます）。

## 画像の差し替え

- **事業内容・フローの画像**：現在は CSS のプレースホルダー（`Image` 枠）です。実画像にする場合は、`front-page.php` の各 `<div class="media-placeholder">…</div>` を `<img>` に置き換えてください。
- **Hero 背景・事例の写真**：現在は Unsplash の URL を直接参照しています。自社画像に差し替える場合は `front-page.php` 内の `src` を変更してください（メディアライブラリにアップした画像の URL でも可）。

## お客様の声の追加・編集

`front-page.php` の `#testimonialTrack` 内にある `<div class="testimonial-slide">…</div>` をコピー／編集することで、スライダーの件数を自由に増減できます（ドットや自動再生は件数に合わせて自動調整されます）。
